CR-25 – BuildingStock / Production Foundation Completion / Regression / Freeze Gate

Der CR-25-Systemabschluss regressiert CR-25A, CR-25B und CR-25C gemeinsam auf dem eingefrorenen CR-24-Unterbau. Geprüft werden der immutable BuildingStock-Vertrag, deterministische add/remove-Mutation, minimale Production->BuildingStock-Ausführung, atomare Ablehnung bei unzureichendem Input sowie ein vollständiger End-to-End-Durchlauf von lokalem Bestand über Mutation bis Produktion. Die CR-25-Grenze bleibt auf Foundation-Niveau: keine Produktionszeit oder Zustandsmaschine, keine Workforce/Professionen, keine Kapazität/Slots, kein Transport, keine Bau-Materialintegration, kein SaveGame und kein Rendering/UI-Gameplay. Nur bei PASS / 0 BLOCKER darf CR-25 als Ganzes COMPLETE / FROZEN werden.
