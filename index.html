CR-06B – Pickup Execution Foundation

Führt den kontrollierten Pickup eines bereits zugewiesenen TransportJobs aus: Nur eine passende reservierte Ressource an der vorgesehenen Quelle darf logisch dem zugewiesenen Carrier als Cargo gebunden werden. Dabei wechselt der Execution-State ausschließlich von TO_PICKUP auf PICKED_UP. CR-05 und CR-06A bleiben vollständig regressiert. Weiterhin 0 Pathfinding, 0 Routing und 0 reale Bewegung.
