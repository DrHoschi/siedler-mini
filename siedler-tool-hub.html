Bedienungsanleitungen (Kurz)

UI-Editor Advanced
• Datei laden/Code einfügen → Vorschau aktualisieren.
• WYSIWYG aktiv → Element im Preview anklicken → Drag zum Verschieben, Ecken zum Resize. Snap-Grid oben anpassbar.
• Änderungen werden als Inline-Styles gesetzt → beim Code kopieren/Zip enthalten.
• Property-Editor: Text/ID/Classes/OnClick, Style-Felder + Inline-CSS, Data-Attributes.
• Komponenten-Bibliothek: „Aus Code übernehmen“ → JSON speichern/laden.
• Assets: URL/GitHub auswählen → passendes Tag wird eingefügt; Drag&Drop unterstützt.
Asset-Library
• Owner/Repo/Branch angeben → Laden → Ordner/Dateien browsen.
• Zu jeder Datei passendes Snippet (script/link/img/json) + Copy-Button.
• Filterfeld oben rechts durchsucht Namen/Pfade.
Node-Playgrounds / DOT
• Playgrounds: visuell verdrahten, JSON/DOT exportieren; Trace zeigt Flow (Play/Step/Pause).
• DOT-Editoren: Blockschaltbilder rendern; Pro-Version hat Ortho/Kanten-Labels/Export.
💡 Tipp: Lege diese Datei in das Projekt-Wurzelverzeichnis – alle Links funktionieren offline.
