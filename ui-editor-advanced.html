Kurzanleitung
  • CSS laden: URL eintragen → „CSS verlinken“. Bei lokalem Öffnen ggf. lokalen Server nutzen.
  • WYSIWYG: Im Preview klicken → Drag = Move, Ecken = Resize. Snap-Grid oben, Nachbar-Snap (Magnet) einstellbar.
  • Inline-Styles: WYSIWYG schreibt left/top/width/height direkt ans Element.
  • Selector-Apply: Mit „Inline-Styles anwenden“ kannst du einem Element (per CSS-Selector) schnell Styles geben.
  • Export: „Code kopieren“, „Speichern“, „ZIP“ – alles inline & offline.
